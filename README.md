# 🎫 Telegram Bot: Регистрация на мероприятия и нетворкинг

Telegram-бот для автоматизации регистрации участников на IT-мероприятия, генерации персональных QR-билетов и быстрого знакомства (нетворкинга) по интересам.

## 🛠 Технологии и стек
- **Python 3.10+**
- **pyTelegramBotAPI (telebot)** — логика интерфейса и обработка кнопок
- **SQLite3** — хранение базы данных участников
- **qrcode** — динамическая генерация QR-кодов в памяти

## 🌟 Основные возможности
- 📝 **Регистрация:** Пошаговое заполнение профиля участника (имя, роль, интересы).
- 🎟 **QR-билеты:** Создание уникального графического QR-кода для прохода на мероприятие.
- 🤝 **Нетворкинг:** Случайный подбор собеседников в системе для профессионального общения.
